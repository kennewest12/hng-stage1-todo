# HNG Stage 1 To-Do List

An AI-built To-Do List application created for HNG Internship 15 Stage 1.

## Planned Features

- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Add and manage notes
- Set task priority
- Filter tasks

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- FastAPI
- Pydantic
- SQLModel
- PostgreSQL

### Testing
- Pytest
- FastAPI TestClient
